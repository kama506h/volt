# VOLT

Локальный монитор компьютера на Python. Интерфейс напоминает печатную приборную панель: тёплая бумага, строгая сетка, графит и сигнальный оранжевый.

## Запуск

Нужен Python 3.10 или новее. Скачайте репозиторий, откройте терминал в папке с README:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m volt
```

Linux / macOS:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m volt
```

Откройте **http://127.0.0.1:8765**. Для остановки нажмите Ctrl+C в терминале. Другой порт: `python -m volt --port 9000`.

## Что показывает

- Общую нагрузку CPU и нагрузку каждого логического ядра.
- Использование оперативной памяти.
- Скорость получения и отправки данных по всем сетевым интерфейсам.
- Занятое место на доступных локальных томах.
- 15 процессов, отсортированных по CPU, затем по памяти.
- Максимальную температуру среди доступных системных датчиков.
- Время работы ОС и графики последних 120 замеров.

Пауза останавливает обновление экрана. Сбор метрик продолжает работать; история хранится только в памяти. Первые значения CPU и скорости сети могут быть нулевыми: для расчёта нужны два замера. Загрузка процесса нормализована на число логических CPU, поэтому 100% означает полную загрузку всей машины. Память процессов — RSS; сумма RSS может учитывать общие страницы несколько раз.

## Ограничения

Мониторит **компьютер, где запущен Python**, а не устройство, открывшее страницу. В контейнере показания могут отражать хост или ограничения контейнера. Датчики зависят от оборудования и ОС; температура часто недоступна в Windows и macOS. GPU не поддерживается. Диски с одинаковым устройством показываются один раз. Скорость сети включает локальные и виртуальные интерфейсы.

Работает на API psutil для Windows, Linux и macOS. Автоматические тесты в GitHub Actions настроены на все три ОС; наличие конкретных датчиков не гарантируется.

Сервер слушает только `127.0.0.1`, не использует CDN, аналитику и внешние запросы. Авторизации нет — не публикуйте порт через прокси. Имена процессов и имя компьютера видны в интерфейсе. Веб-сервер стандартной библиотеки предназначен для локального использования.

## Структура

```text
volt/
  collector.py       # один сборщик для всех вкладок
  __main__.py        # HTTP API и запуск
  static/            # HTML, CSS, JS без сборки и зависимостей
 tests/              # unittest
```

Проверка из корня проекта:

```bash
python -m unittest discover -s tests -v
```

```bash
git init

git branch -M main
git remote add origin https://github.com/YOUR_NAME/volt.git
git push -u origin main
```

Замените `YOUR_NAME` на свой логин. Не добавляйте `.venv` и файлы с личными данными. Лицензия MIT позволяет менять и распространять проект.
